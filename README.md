# Zodiac — 쿼터뷰 3D 액션 로그라이크

졸업 작품으로 1인 개발한 쿼터뷰 3D 액션 로그라이크 게임입니다.
콘텐츠가 늘어나도 코드가 함께 늘어나지 않는 **데이터 기반 구조**를 중심으로 설계했습니다.

## 기술

### 1. 데이터 기반 스킬 시스템
- 대시, 투사체 발사, 연속 공격, 데미지 판정 등 **행동 단위를 ScriptableObject로 분리**하고, 스킬은 행동의 조합으로 정의합니다.
- 스킬 발동 시 행동 목록을 **코루틴으로 순서대로 실행**합니다.
- 새 스킬은 코드 작성 없이 기존 행동 에셋을 조합해 추가할 수 있습니다.

### 2. 스킬 획득과 강화
- 스테이지 클리어 시 무작위 스킬 카드 중 하나를 선택해 획득합니다.
- 장착 슬롯이 가득 차면 **‘불씨’로 보유 스킬을 강화**하도록 유도합니다.
- 기본 수치는 데이터에 고정하고 **강화 단계만 상태로 관리**해, 배율이 중복 적용되는 문제를 막았습니다.

### 3. 보스 패턴 시스템
- 패턴을 **준비 → 이동 → 예고 → 공격 → 후딜** 스텝 배열(ScriptableObject)로 정의하고 코루틴으로 실행합니다.
- 스텝 발동 방식은 **시간 기반**과 **예고 진행도 기반** 두 가지이며, 후자로 위험 범위 표시와 실제 판정 시점을 일치시켰습니다.
- 체력 비율에 따라 페이즈가 전환되고, 공격 속도 배율에 맞춰 애니메이션 속도도 함께 조정합니다.

### 4. 전투 판정과 적 AI
- 공격 형태별 판정: 원형(구 범위), 직선(박스 범위), 부채꼴(구 범위 + 각도 필터), 고속 투사체(이동 경로 구 캐스트)
- 레이어 마스크로 적만 검사하고, 공통 데미지 인터페이스로 전달합니다.
- 적은 **상태 머신**(대기 · 추격 · 공격 · 후퇴)에 **공격 컴포넌트**(근접 · 차지 · 투사체 · 레이저 등)를 조합해 6종을 구성했습니다.
- 스테이지마다 NavMeshSurface로 NavMesh를 런타임 생성합니다.

### 5. 스테이지와 런 진행
- 클리어 판정과 전환은 공통 기반 클래스에서 관리합니다.
- 보스 사망, 페이즈 전환은 이벤트로 발행해 필요한 시스템만 구독합니다.
- 런 종료 시 스킬, 능력치, 일시 효과를 모두 초기화합니다.

## 트러블슈팅

### 에디터에선 되는데, 빌드에선 적이 움직이지 않는 문제
- **상황**: 에디터에서는 정상 추적, 빌드에서는 특정 스테이지의 적이 출발 지점에서 멈춤
- **원인**: 런타임 NavMesh 생성 기준이 렌더링 메시였고, 빌드에서는 메시 Read/Write가 비활성화되어 빈 NavMesh가 생성됨
- **해결**: 생성 기준을 콜라이더로 변경하고 빌드 환경에서 정상 동작 확인
- **배운 점**: 에디터에서의 동작만으로는 충분하지 않으며, 배포 환경 기준의 검증이 필요함

### 능력치 누적 오류
- 레벨 설정이 반복 호출되면 계수가 중복 적용되던 문제를, 원본 값을 보관하고 항상 원본 기준으로 재계산하도록 바꿔 해결

### 히트 스톱 중첩
- 여러 적을 동시에 타격할 때 정지 효과가 겹치던 문제를, 일정 시간 내 중복 호출을 무시하도록 처리해 해결
